# TripiWiki

A local-first travel guide, interactive map, railway guide, and live weather tracker for Laos—built with Rust (Axum + Askama + HTMX + Leaflet).

## Run Locally

```bash
cargo run
```

Open `http://127.0.0.1:3000`.

## Deploy on Render

Push this repository to GitHub and create a new **Blueprint** (or **Web Service**) on [Render](https://dashboard.render.com) — `render.yaml` and `Dockerfile` are pre-configured for the free tier in Singapore.
